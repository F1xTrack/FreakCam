# FreakCam

FreakCam is a Minecraft Forge mod for sharing webcam video between players.

- `1.7.10/` contains the Minecraft 1.7.10 project.
- `1.20.1/` contains the Minecraft 1.20.1 port.

Each directory is an independent Gradle project; run its Gradle wrapper from that directory. The 1.7.10 directory retains documentation and license files from the original project template.
